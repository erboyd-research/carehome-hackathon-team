# Omega Digital visual reference

The local app's visual design follows the user's reference at https://omegalifedigital.uk/submissions/ and the supplied screenshot. That page embeds https://omega-hackathon-submit-2026.omega-digita-0373.chatgpt.site/submissions.

## Design tokens

- Primary red: `#c9302c`, hover `#ad2723`.
- Logo background: `#f04e50`.
- Ink: `#141b2d`.
- Muted text: `#5c6270`.
- Page background: `#f6f5f1`.
- Card/header surface: `#fffdfa`.
- Fine borders: `#e1e1dd`.
- Soft red: `#faefec`.
- Typography: Poppins Regular and SemiBold, with Arial/sans-serif fallback.

Use a clean white brand header, generous spacing, bold dark headings, red step labels, fine-bordered cards and red primary actions. Preserve the app's responsive layout and accessible focus/error treatments.

## Bundled assets

The public reference site's `omega-digital-logo.png`, `fonts/Poppins-Regular.ttf` and `fonts/Poppins-SemiBold.ttf` are stored in `public/brand/` so this local app does not need remote assets at runtime. Poppins is distributed under the SIL Open Font License; the license from https://github.com/google/fonts/blob/main/ofl/poppins/OFL.txt is bundled beside the fonts.

This is a hackathon prototype styled at the user's request. Branding changes do not alter repair data, storage format, validation or history.
